# Anime Watchlist

中文名：追番计划

一个基于 Bangumi API 的追番软件。

这里的番包括：漫画、动画，在 API 参数中对应 `SubjectType=1`（书籍）& `SubjectType=2`（动画）。

应用并不展示从 Bangumi 获取的全部数据，仅展示必要的。

## 1. 技术栈

使用 Tauri 2 构建的桌面应用，只支持 Windows 平台。技术栈：React 19 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui + TanStack Query。本地仅存储凭据/令牌/代理/偏好（`tauri-plugin-store` 落到 `config.json`），业务数据不落库、始终从 Bangumi API 实时获取。

## 2 整体布局

侧边栏 + 内容区

### 2.1 侧边栏

- 追番（首页）
- 新番（每日放送）
- 找番（搜索 + 热度榜）
- 配置
- 关于

底部有主题切换按钮：亮色 → 暗色 → 跟随系统 三态循环，默认跟随系统。

### 2.2 内容区

顶部标题，下方其余空间展示内容。追番/新番/找番三个页面常驻保活（隐藏不卸载），切换页面不丢搜索词、结果与滚动位置。全局快捷键 `/` 聚焦当前页搜索框。

## 3 页面布局

### 3.1 追番（首页）

顶部标题：追番，标题下方是工具栏（快速导航到各收藏夹、按条目类型筛选漫画/动画、刷新、一键折叠/展开全部）。

从上至下依次展示 在看/想看/看过/搁置/抛弃 五个收藏夹。

这五个栏目可以点击栏目标题实现折叠和展开。工具栏支持 列表/网格 两种视图（网格为海报墙，持久化）。

列表展开状态下，列出该栏目所有番：

```
在看                                         >
封面 | 标题 [↗] [收藏▾]（标题行可打开 Bangumi、收藏/移动/取消收藏）
     | 简介、放送时间、我的进度/评分、标签
封面 | ...
```

点击行展开统一详情（与弹窗同一渲染单元）：条目字段（含 infobox「更多信息」折叠）、标签、
「我的」折叠栏（我的评分 / 我的进度 / 我的备注，仅在看·看过显示评分与进度）、
简介（BBCode 清洗 + 长文折叠）、角色 CV / 关联条目 / 相关推荐（p1，滚动可见才请求；
仅无数据时静默隐藏，已加载内容在后台重拉失败时保留；关联/推荐以海报卡片网格展示，点击卡片在应用内打开对应条目的详情弹窗）。

### 3.2 新番（每日放送）

基于 `GET /calendar` 的每日放送表：表格视图（七列封面卡片，点击弹出详情弹窗）与列表视图（按星期折叠），支持精简模式（按在看人数阈值过滤）。详情弹窗与追番展开详情同一渲染单元，可直接收藏与编辑进度。

### 3.3 找番

顶部标题：找番。空态显示热度榜（p1 新增热度，接口失败自动兜底为日历追番人数榜）。

```
[漫画/动画名称] [类型筛选▾] [查找]
```

用户输入名字，点击查找，应用会基于 BGM 的 `POST /v0/search/subjects 条目搜索` API 显示所有漫画（`SubjectType=1`）、动画（`SubjectType=2`）。

然后在下方列出查找列表（分页加载），标题行带 收藏下拉 与 Bangumi 链接，展开可查看统一详情。

### 3.4 配置

#### 3.4.1 未认证

显示一个 Bangumi 认证按钮，点击后，根据官方文档（见 `docs/API.md` 认证章节）中定义的 OAuth 2.0 认证流程完成认证。

#### 3.4.2 已认证

显示用户头像，昵称，用户名，签名，和一个注销按钮。

#### 3.4.3 网络代理（始终显示）

无论是否已认证都显示。所有 Bangumi API 请求可经此代理转发，用于在受限网络环境下访问 API。表单含：

- 代理地址（必填，如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`）
- 用户名 / 密码（可选，用于代理的 Basic 认证）
- 「测试连接」按钮：用当前表单值请求一次 Bangumi 验证代理是否可用
- 「保存」按钮：保存后对所有请求立即生效；地址留空保存即关闭代理、恢复直连

标题旁有状态徽章区分「已保存 / 未配置 / 未保存修改」，保存成功后显示带勾徽章并自动淡出；保存按钮在无改动时置灰。

> 注意：封面/头像图片走 webview 网络栈，不经过此代理。

### 3.5 关于

显示应用名、版本号（构建时从 `package.json` 注入）、简介、免责声明与相关链接。
