基于 Bangumi API 的 Windows 桌面追番软件。本次为大版本更新，涵盖自 v1.9.0 以来的 40+ 项改进。

## ✨ 新功能

- **角色 / CV**：角色与声优详情弹窗（可递归跳转）、大图查看（点角色图 / 弹窗头像放大）、横向滚动默认全量展示
- **剧集列表**：按话展示、已看高亮 / 未播置灰、单话简介行内展开
- **统计页**：新增第 6 页——收藏 KPI、类型与收藏夹构成、评分直方图、开播年份分布（纯缓存聚合，零额外请求）
- **数据备份与恢复**：全部收藏导出 JSON；增量恢复（跳过 / 覆盖双模式，带进度与失败汇总）
- **找番增强**：列表 / 网格视图、搜索结果排序、高级筛选（年份区间 / 最低评分）、搜索历史
- **今日放送**：在看 / 想看条目「今天更新」标识与分组计数
- **封面体验**：cover:// 磁盘缓存协议（代理环境不裂图、离线可看）、横版与方形封面完整显示不裁切
- **桌面基础**：窗口状态记忆、Ctrl+1..6 切页、未登录引导

## 🛠 修复与改进

- OAuth 稳定性：端口事件竞态、token 原子落盘、各失败分支兜底
- 网络与数据：请求整体超时、乐观更新并发防护、恢复不再重置公开收藏
- 界面与可访问性：暗色模式原生控件配色、系统「减弱动效」支持、键盘导航与读屏语义、时区判定 / 裂图兜底等一批细节修复
