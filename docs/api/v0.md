# Bangumi v0 API 说明

- **API Base URL**：`https://api.bgm.tv`（v0 接口）
- **OAuth Base URL**：`https://bgm.tv`
- **User-Agent**：`GitZhiQing/anime-watchlist/(version) (PC) (https://github.com/GitZhiQing/anime-watchlist)`

> 除 v0 外，本应用还使用 Web 前端的 **p1 私有 API**（`next.bgm.tv`）获取热度榜，见 [p1 API 说明](p1.md)。

## 认证（OAuth 2.0 Authorization Code）

官方原始文档：https://github.com/bangumi/api/blob/master/docs-raw/How-to-Auth.md

流程：引导用户访问授权页 → 拿到 `code` → 用 `code` 换 Access Token → Header 携带访问 API。

**1. 引导授权**

```
GET https://bgm.tv/oauth/authorize
```

| 参数              | 说明                     |
| ----------------- | ------------------------ |
| `client_id`     | App ID（注册应用时获取） |
| `response_type` | 固定`code`             |
| `redirect_uri`  | 后台设置的回调地址       |
| `state`         | 随机参数，防 CSRF        |

**2. 用 code 换 token**

```
POST https://bgm.tv/oauth/access_token
```

`grant_type=authorization_code`，参数：`client_id`、`client_secret`、`code`、`redirect_uri`。`code` 有效期 60 秒。

返回：

```json
{ "access_token": "...", "expires_in": 604800, "token_type": "Bearer",
  "scope": null, "refresh_token": "...", "user_id": 123 }
```

**3. 刷新 token**（同样 `POST /oauth/access_token`）

`grant_type=refresh_token`，参数：`client_id`、`client_secret`、`refresh_token`、`redirect_uri`。返回新的 access_token + refresh_token。

**4. 访问 API**

```
Authorization: Bearer <access_token>
```

> 注意：v0 接口**不允许**用 query string 传 token，必须走 Authorization Header。

**本应用实现**：`src/lib/auth.ts`（流程编排）+ `src-tauri/src/lib.rs`（本地回环服务器收 code，动态端口 7359–7369，`redirect_uri` 用动态值 `http://localhost:{port}/callback`，符合 RFC 8252 loopback，无需后台登记回调地址）。401 自动刷新逻辑见 `src/lib/bgm.ts` 的 `bgmRequest`/`refreshAccessToken`。

## 关键 API

### POST /v0/search/subjects 条目搜索

通过此 API，实现用户仅输入漫画、动画名时的条目查找。本应用固定 `filter: { type: [1, 2] }`（书籍+动画）。

### GET /v0/subjects/ 获取条目

通过此 API，实现通过 ID 获取条目具体信息。

### GET /v0/subjects//image Get Subject Image

通过此 API，获取条目封面，本应用默认使用最高画质。

### GET /v0/me Get User

通过此 API，在用户认证完成后，获取用户信息。

### GET /v0/users//collections 获取用户收藏

获取用户的收藏夹信息。支持 `subject_type` 过滤、`limit`/`offset` 分页；本应用按类型并发翻页抓全量（见 `src/lib/bgm.ts` 的 `getAllUserCollections`）。

### POST /v0/users/-/collections/ 新增或修改用户单个条目收藏

用于将某个条目添加到某个收藏夹。

```
{
  "type": 3,
  "rate": 10,
  "ep_status": 0,
  "vol_status": 0,
  "comment": "string",
  "private": true,
  "tags": ["string"]
}
```

rate、ep_status、vol_status、comment、tags 大部分情况下不设置（直接去除）。private 保持为 true。

### PATCH /v0/users/-/collections/ 修改用户单个收藏

用于修改某个条目的收藏夹。

虽然文档中写"由于直接修改剧集条目的完成度可能会引起意料之外效果，只能用于修改书籍类条目的完成度"，但实际测试仅仅是改变收藏夹是没问题的。

```
{
  "type": 3,
  "rate": 10,
  "ep_status": 0,
  "vol_status": 0,
  "comment": "string",
  "private": true,
  "tags": ["string"]
}
```

一般只需要传入新的 type 值，其他参数不设置。
