## 总评

- 强项：TanStack Query 缓存与乐观更新精准失效、SubjectDetailView 统一详情容器、p1 私有接口宽松解析静默降级、错误态/骨架屏覆盖面广。
- 短板模式：功能做深了单个页面（追番页最全），但**能力未横向拉平**（见[体验债速查表](#体验债速查表)）；**已 fetch 的数据大量未呈现**（airdate/rating.count/单话简介/角色身份，见 U-1/U-2/U-3/U-9）；**触达与激活为零**（无提醒、无自动更新、认证门槛高，见 PM-1/PM-2/PM-3）。

## 产品经理视角清单

### PM-1 激活漏斗在第一步就断裂（→ P0-1）

首次启动落地空追番页，只有一行文字「请先到「配置」页完成 Bangumi 认证」（`src/App.tsx:270`），无按钮无链接，用户需自行发现 16px 图标侧边栏；配置页还要求先去 bgm.tv/dev/app 注册开发者应用拿 client_id/secret（`src/pages/Config.tsx:336`）。「不内置凭据」是隐私上的正确决策，但产品后果是绝大多数目标用户走不完流程。游客其实能浏览新番/热度榜/搜索，但这个价值被空落地页埋没。

- [x] 未登录时默认落地页改为新番或找番页（游客可浏览）
- [x] 追番页未登录空状态加「去认证」跳转按钮（找番页未登录提示同样只有文字，`src/pages/Collection.tsx:128`）
- [x] OAuth 凭据获取做逐步引导向导（截图/外链/字段说明）
- [ ] 可选：评估发放共享公共凭据或引导申请一次性凭据的折中方案

### PM-2 留存钩子为零（→ P0-2）

无放送提醒、无「今天你的番更新了」任何触达。用户打开→看一眼→关掉，回访完全靠自发习惯。桌面追番工具的核心留存场景恰恰是「更新了来提醒我」。

- [ ] 应用内「今日更新」角标/摘要（依赖 U-1）
- [ ] 系统级放送提醒（`tauri-plugin-notification`，注意需申请权限）

### PM-3 分发与版本触达

便携 zip、`bundle.active=false` 无安装包、无 updater 插件。老用户永久停在下载时的版本，release 做得再勤也触达不到存量用户，版本碎片化。

- [ ] 接入 `tauri-plugin-updater`（需要签名与更新源，工作量较大，可先评估）
- [ ] 备选：启动时检查 GitHub latest release 并提示下载（轻量方案）
- [ ] 关于页加「检查更新」入口

### PM-4 备份承诺过度、兑现不足

Tooltip 写「用于留存或**迁移**」（`src/pages/Config.tsx:630`）但没有任何导入路径；导出只有 `ep_status` 汇总数，**逐集观看标记不导出**，用户出事后恢复才发现少了数据。且「上游无删除端点所以不做导入」的推理把可交付的部分也放弃了——**部分导入可行**：POST 收藏后 PATCH 回评分/进度/备注（增量恢复，只有「删多余」做不到，见 L-1/L-2）。

- [x] Tooltip 文案先改为「用于留存」直到导入实现
- [x] ~~导出补齐逐集观看标记~~ **明确不做**：API 无「读取已看单集」端点，只能按 ep_status 推断「前 N 话」，网页端非连续勾选会被改写——2026-10-12 决策放弃逐集路径，聚合恢复已足够（见 L-6）
- [x] 实现部分导入（增量恢复：新增缺失收藏 + PATCH 覆盖评分/进度/备注，明确提示「不删除多余条目」）

### PM-5 体验债（→ 汇总至[体验债速查表](#体验债速查表)，逐项偿还）

三页能力不对称叠加产生「半成品感」。单独条目见 D-1~D-12。

### PM-6 错误恢复死角

收藏按钮失败后变成灰色的「收藏失败」死按钮，无重试入口（`src/components/CollectAction.tsx:84`）。

- [x] CollectAction 失败态提供重试（或恢复原按钮可再次点击）

### PM-7 结构性缺位（对个人项目可以是选择，但要自知）

- 单账号无切换（须注销重走 OAuth）
- 无任何用户反馈/崩溃上报渠道（隐私优先的个人项目可接受，属明确取舍）
- Windows 单平台，「通勤路上顺手标一话」的高频移动场景缺位
- 无多语言（纯中文 UI）

### PM-8 自动化与数据可观测

无启动性能记录、无 API 失败率统计，出问题只能靠用户口述。

- [ ] 可选：本地日志文件（tauri-plugin-log）辅助排查代理/网络问题

## 二次元用户视角清单

### U-1 没有放送提醒、没有「下一话」指示（→ P0-2，感知最强）

`getEpisodes` 已拉到每话 `airdate`（`src/lib/bgm.ts:463`），目前只用于进度按钮置灰与 tooltip。「我追的番今天更新了吗」只能开应用翻日历肉眼找。

- [ ] 在看条目行/卡片显示「今天播出 / X 天后第 N 话」角标（本季数据 `["calendar"]` 缓存 + 详情缓存已有，判断下一话只需对比 ep_status 与 airdate）
- [ ] 新番页本季模式「跳到今天」快捷入口（今日组虽有高亮，长列表下不够）
- [ ] 系统放送提醒（与 PM-2 合并实现）

### U-2 剧集列表不可浏览

每话标题/播出日期/时长 fetch 了，单话简介 `desc` 也 fetch 了但从未渲染（`src/lib/bgm.ts:452`）。想查「这周播到第几话、标题是什么」只能跳网页。

- [ ] 详情视图增加剧集列表区块（话数/标题/播出日期，复用 `["episodes", id]` 缓存；单话简介可折叠）

### U-3 角色/CV 区截断且无出口

角色封顶 16、关联条目 12、推荐 8（`src/components/SubjectP1Sections.tsx:37-39`），无「查看全部」；只显示第一位 CV；主角/配角身份（`type`）不显示；不能点进角色/声优页。

- [ ] 「查看全部」展开（p1 分页或本地全量渲染）
- [ ] 显示角色身份（主角/配角）与多位 CV
- [ ] 可选：角色/声优详情弹窗（需 p1 人物接口，形状待实测）

### U-4 收藏数据写死私密、个人标签不能编辑

所有写操作硬编码 `private: true`（`src/lib/bgm.ts:415`、`src/lib/bgm.ts:436`）；个人 `tags` 字段类型里有（`src/types/bgm.ts:184`）、备份里有，UI 却不能编辑。

- [ ] 「我的」折叠栏增加私密开关（写操作透传用户选择，默认仍私密）
- [ ] 「我的」折叠栏增加个人标签编辑（PATCH `tags` 字段）

### U-5 不能取消收藏（API 硬限制，见 L-1）

误收藏只能永久留着或去网页删。

- [ ] 缓解：收藏菜单加「到网页管理收藏」深链（条目页右上有管理入口）

### U-6 找番能力太浅

搜索只有关键词+类型，无年份/季度/评分/标签过滤，结果不能排序、无网格视图。「找 2020 年代评分 8+ 的原创番」这类真实诉求满足不了。

- [ ] 高级筛选（年份区间/最低评分/NSFW 开关——`/v0/search/subject` 的 `filter` 支持程度需实测，见 `docs/API.md`）
- [x] 结果排序（至少按评分/收藏人数）
- [x] 结果网格视图（复用 SubjectGridCard）

### U-7 代理用户封面裂图（→ P0-3）

API 请求走 Rust 侧代理，但封面/头像图片走 WebView 直连不经代理（AGENTS.md 已注明）。挂代理才能访问 Bangumi 的用户会出现「列表数据都出来了、封面全是裂图」的割裂体验。

- [ ] 评估：封面走 Rust 侧 `convertFileSrc`/自定义协议代理，或 WebView2 代理设置（`additionalBrowserArguments` 透传 `--proxy-server`）
- [ ] 最低成本：裂图占位提示「图片需直连 lain.bgm.tv，当前代理配置下可能无法加载」

### U-8 桌面基础体验缺角

窗口尺寸/位置每次启动重置 1200×800（无 window-state 插件）；无离线能力（重启断网只剩错误横幅，封面无磁盘缓存）；快捷键只有 `/`。

- [ ] 接入 `tauri-plugin-window-state`
- [ ] 可选：磁盘缓存封面（自定义协议 + 本地缓存目录）
- [ ] 可选：补充快捷键（`j/k` 上下行、`Enter` 展开详情、数字键切页）

### U-9 没有统计页

评分分布直方图数据（`rating.count`）已 fetch 未渲染（`src/types/bgm.ts:103`）；无类型占比、无年度总结。Bangumi 用户对「年度报告」热情被验证过。

- [ ] 统计页/配置页内嵌统计卡：各收藏夹数量、类型占比、我的评分分布、年度加入曲线（数据全在本地缓存，无需新端点）

### U-10 没有「今天看什么」

想看列表很长时的随机推荐/决策助手，追番工具常见甜点功能。

- [ ] 找番页或追番页空态加「随机一部」按钮（想看列表随机抽一，直接开详情弹窗）

## API 硬限制备忘（勿重复立项，见 docs/API.md）

未来会话直接引用，避免重新调研：

- **L-1 无取消收藏端点**：官方 OpenAPI 对 `/v0/users/-/collections/{subject_id}` 只定义 POST/PATCH；服务端 DELETE 注释 `TODO: wait for soft delete`，实测 404。**只能缓解（U-5 深链），不能实现**。
- **L-2 POST 收藏体仅 `{type, private}`**：评分/进度/备注/标签创建时不可带，需 PATCH 二次写——导入功能必须 POST+PATCH 两步。
- **L-3 PATCH 非 type 字段必带 `private`**：服务端强制要求，漏带会重置私密状态。
- **L-4 `GET /v0/subjects` 按月取季度**：`type` 必填（缺省静默返回空）；必须默认 `sort=date`（`sort=rank` 静默丢无排名条目）；响应无 `air_weekday`（季度模式只能按月分组，已实现）。
- **L-5 p1 私有接口形状会漂移**：解析统一收口 `src/lib/p1.ts`，改形状只动该文件；部分条目数据为空属正常（按空隐藏非异常）。
- **L-6 单集标记端点路径无 subject_id**：`PUT /v0/users/-/collections/-/episodes/{episode_id}` 用全局剧集 id，type 2=看过 0=未看。
- **L-7 图片域名白名单**：capabilities 的 HTTP 域名白名单须包含任何新增域名（封面 CDN `lain.bgm.tv` 走 WebView 直连不占白名单，若 U-7 改走 Rust 侧需登记）。
