## 产品经理视角清单

### PM-1 激活漏斗在第一步就断裂（→ P0-1）

首次启动落地空追番页，只有一行文字「请先到「配置」页完成 Bangumi 认证」（`src/App.tsx:270`），无按钮无链接，用户需自行发现 16px 图标侧边栏；配置页还要求先去 bgm.tv/dev/app 注册开发者应用拿 client_id/secret（`src/pages/Config.tsx:336`）。「不内置凭据」是隐私上的正确决策，但产品后果是绝大多数目标用户走不完流程。游客其实能浏览新番/热度榜/搜索，但这个价值被空落地页埋没。

- [x] 未登录时默认落地页改为新番或找番页（游客可浏览）
- [x] 追番页未登录空状态加「去认证」跳转按钮（找番页未登录提示同样只有文字，`src/pages/Collection.tsx:128`）
- [x] OAuth 凭据获取做逐步引导向导（截图/外链/字段说明）
- [ ] 可选：评估发放共享公共凭据或引导申请一次性凭据的折中方案

### PM-2 留存钩子为零（→ P0-2）

无放送提醒、无「今天你的番更新了」任何触达。用户打开→看一眼→关掉，回访完全靠自发习惯。桌面追番工具的核心留存场景恰恰是「更新了来提醒我」。

- [ ] 应用内「今日更新」角标/摘要（依赖 U-1）
- [ ] 系统级放送提醒（`tauri-plugin-notification`，注意需申请权限）

### PM-3 分发与版本触达

便携 zip、`bundle.active=false` 无安装包、无 updater 插件。老用户永久停在下载时的版本，release 做得再勤也触达不到存量用户，版本碎片化。

- [ ] 接入 `tauri-plugin-updater`（需要签名与更新源，工作量较大，可先评估）
- [ ] 备选：启动时检查 GitHub latest release 并提示下载（轻量方案）
- [ ] 关于页加「检查更新」入口

### PM-4 备份承诺过度、兑现不足

Tooltip 写「用于留存或**迁移**」（`src/pages/Config.tsx:630`）但没有任何导入路径；导出只有 `ep_status` 汇总数，**逐集观看标记不导出**，用户出事后恢复才发现少了数据。且「上游无删除端点所以不做导入」的推理把可交付的部分也放弃了——**部分导入可行**：POST 收藏后 PATCH 回评分/进度/备注（增量恢复，只有「删多余」做不到，见 L-1/L-2）。

- [x] Tooltip 文案先改为「用于留存」直到导入实现
- [x] ~~导出补齐逐集观看标记~~ **明确不做**：API 无「读取已看单集」端点，只能按 ep_status 推断「前 N 话」，网页端非连续勾选会被改写——2026-10-12 决策放弃逐集路径，聚合恢复已足够（见 L-6）

`getEpisodes` 已拉到每话 `airdate`（`src/lib/bgm.ts:463`），目前只用于进度按钮置灰与 tooltip。「我追的番今天更新了吗」只能开应用翻日历肉眼找。

## API 硬限制备忘（勿重复立项，见 docs/API.md）

未来会话直接引用，避免重新调研：

- **L-1 无取消收藏端点**：官方 OpenAPI 对 `/v0/users/-/collections/{subject_id}` 只定义 POST/PATCH；服务端 DELETE 注释 `TODO: wait for soft delete`，实测 404。**只能缓解（U-5 深链），不能实现**。
- **L-2 POST 收藏体仅 `{type, private}`**：评分/进度/备注/标签创建时不可带，需 PATCH 二次写——导入功能必须 POST+PATCH 两步。
- **L-3 PATCH 非 type 字段必带 `private`**：服务端强制要求，漏带会重置私密状态。
- **L-4 `GET /v0/subjects` 按月取季度**：`type` 必填（缺省静默返回空）；必须默认 `sort=date`（`sort=rank` 静默丢无排名条目）；响应无 `air_weekday`（季度模式只能按月分组，已实现）。
- **L-5 p1 私有接口形状会漂移**：解析统一收口 `src/lib/p1.ts`，改形状只动该文件；部分条目数据为空属正常（按空隐藏非异常）。
- **L-6 单集标记端点路径无 subject_id**：`PUT /v0/users/-/collections/-/episodes/{episode_id}` 用全局剧集 id，type 2=看过 0=未看。
- **L-7 图片域名白名单**：capabilities 的 HTTP 域名白名单须包含任何新增域名（封面 CDN `lain.bgm.tv` 走 WebView 直连不占白名单，若 U-7 改走 Rust 侧需登记）。
